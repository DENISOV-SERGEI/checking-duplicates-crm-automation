# Проверка дубликатов перед внесением в CRM

Автоматизация на n8n для приёма заявок, поиска дубликатов по телефону или email, ветвления логики с отправкой уведомлений менеджерам и клиентам.

## Описание
Workflow решает задачу ручной проверки дубликатов заявок в CRM. При поступлении заявки через веб-форму нормализуется телефон и email, параллельно проверяется наличие записей в таблице NocoDB. В зависимости от результата:
- Создаётся новый лид (с уведомлением менеджера и письмом клиенту)
- Или регистрируется дубликат (с повторным письмом и предупреждением менеджеру)
- Повторные заявки за последние 5 минут игнорируются.

Отдельный workflow‑обработчик ловит ошибки и пишет их в Google Sheets + Telegram администратору.

## Требования
- n8n (self-hosted, версия ≥ 2.0)
- NocoDB (с таблицами Leads и Duplicates)
- Telegram Bot (токен, chat_id менеджера)
- SMTP сервер
- Google Sheets (для логов ошибок)

## Установка и настройка
1. Импортируйте два workflow из папки `workflows/` в ваш n8n.
2. Настройте credentials:
   - NocoDB API Token
   - Telegram API (@AlbatoCourse_bot)
   - SMTP (den.sa@bk.ru)
   - Google Sheets OAuth2
3. Проверьте переменные окружения: workspaceId, projectId, таблицы (mwclrxvlb31ha6w, m2z4uip08o7iytm), chat_id (962790782).
4. Активируйте оба workflow.
5. В основном workflow укажите в поле `errorWorkflow` ID обработчика (в настройках workflow).
